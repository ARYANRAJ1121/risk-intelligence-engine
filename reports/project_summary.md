# Risk Intelligence Engine — Project Summary Report

### Credit Risk ML Pipeline | Layers 1–5 | March 2026

---

## Project Overview

The **Risk Intelligence Engine** is a full-stack credit risk analytics platform that processes raw loan data through 5 layers of increasing intelligence:

| Layer | Name | Technology | Status |
|---|---|---|---|
| **1** | Data Engineering | PySpark + Pandas + Parquet | ✅ Complete |
| **2** | ML PD Model | Scikit-learn + XGBoost + LightGBM | ✅ Complete |
| **3** | Deep Learning | PyTorch (Autoencoder + LSTM) | ✅ Complete |
| **4** | Stress Testing | Macro scenarios (planned) | 🔲 Planned |
| **5** | Dashboard & Reports | Streamlit + Plotly + Model Cards | ✅ Complete |

## Key Results

### Best PD Model: Random Forest

- **AUC-ROC:** 0.8687 (Excellent — industry threshold is 0.75+)
- **Gini:** 0.7375 (Strong discriminatory power)
- **KS:** 0.5883 (Excellent — exceeds 0.40 threshold)

### Portfolio Risk (GMSC)

- **22,409 loans** evaluated
- **$336M** total exposure
- **$46.6M** expected loss (13.85% of EAD)
- 5 risk grades (A through E) with full Basel III segmentation

### Deep Learning Anomaly Detection

- Autoencoder catches **structural fraud patterns** invisible to tree models
- Anomalous loans default at a significantly higher rate than normal loans
- LSTM framework ready for time-series credit deterioration analysis

## Technical Architecture

```
Raw Data (CSV)
    │
    ▼
Layer 1: PySpark Ingestion → Feature Engineering → Parquet Feature Store
    │
    ▼
Layer 2: 4-Model Tournament → SMOTE → Best Model Selection → SHAP → Basel III EL
    │
    ▼
Layer 3: PyTorch Autoencoder (Anomaly) + LSTM (Time-Series Deterioration)
    │
    ▼
Layer 5: Streamlit Dashboard (Plotly Interactive) + Model Card + Validation Report
```
